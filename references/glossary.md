# Glossary — Enterprise SOC Detection Lab v2

| Term | Definition |
|------|-----------|
| **ATT&CK** | Adversarial Tactics, Techniques, and Common Knowledge — MITRE's knowledge base of adversary behavior |
| **C2** | Command and Control — infrastructure used by attackers to communicate with compromised systems |
| **DET** | Detection — prefix for detection rule IDs in this lab |
| **EDR** | Endpoint Detection and Response — agent-based endpoint security platform |
| **Event ID** | Numeric identifier for a specific type of Windows log entry |
| **False Positive** | A detection alert that fires on legitimate, non-malicious activity |
| **IOC** | Indicator of Compromise — observable artifact indicating a system may be compromised |
| **IR** | Incident Report / Investigation Report |
| **LSASS** | Local Security Authority Subsystem Service — Windows process storing authentication credentials |
| **MITRE** | Non-profit research organization that maintains the ATT&CK framework |
| **SPL** | Search Processing Language — Splunk's query language |
| **SMB** | Server Message Block — Windows network file sharing protocol |
| **SOC** | Security Operations Center |
| **Sysmon** | System Monitor — Microsoft Sysinternals tool providing advanced Windows telemetry |
| **Tactic** | The adversary's tactical goal — why they are performing an action |
| **Technique** | How an adversary achieves a tactical goal |
| **True Positive** | A detection alert that correctly identifies actual malicious or suspicious activity |
| **TTP** | Tactics, Techniques, and Procedures — the behavioral fingerprint of an adversary |
| **WEF** | Windows Event Forwarding — native Windows mechanism for centralizing event logs |
